# Phase 7: Bug fixing

## Overview
Resolve the issues found in the manual test pass (Phase 6). Scope is defined by the **Findings** table at the bottom of `phase-6-manual-testing.md` — this doc is filled in once that table has entries.

## Scope
- Fix findings ordered by severity: blockers first, then annoying, then cosmetic
- Re-run the failing scenario(s) from Phase 6 after each fix and tick them
- Add a row per fix below (finding # → cause → fix)

## Not included
- New features — anything new goes into its own phase or a deferred doc
